How to install

  1. Open this page in Chrome or Edge on a computer (Windows, macOS or Linux).
  2. Connect the board with a USB-C data cable. On the T-Deck, switch it on.
  3. Click the install button for your board and choose its port in the list (it shows as USB JTAG/serial debug unit).
  4. When asked, choose Erase device if the board ran other firmware before (MeshCore, Meshtastic and so on).
  5. Wait until the page reports that the installation is complete. The board restarts by itself.
The port does not appear, or the connection fails? Start the board in download mode: hold the BOOT button (on the T-Deck: press and hold the trackball), plug in the cable or tap RESET, then release it and click install again. After installing, unplug and plug in the board once.

Flashing by hand

The release page has complete T-Deck images. They contain bootloader, partition table and program, so they go to address 0x0:

esptool.py --chip esp32s3 write_flash 0x0 tdeck-datv-<version>-tdeck-16MB.bin

Source code and app downloads on GitHub. Flashing uses ESP Web Tools.
